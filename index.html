Featured Projects

University of Liverpool research implementations

01

Retail Sales Forecasting with Sentiment Analysis

Built ARIMA, SARIMA and ARIMAX models integrating VADER sentiment analysis from customer reviews.

Impact: 15% RMSE reduction vs baseline models.

Project Overview

As part of my Master's dissertation at the University of Liverpool, I developed a comprehensive forecasting system that combines traditional time series analysis with natural language processing to predict retail sales more accurately.

Methodology

  • Data Collection: Gathered historical sales data spanning 3 years alongside customer review text from multiple retail channels
  • Sentiment Analysis: Implemented VADER (Valence Aware Dictionary and sEntiment Reasoner) to extract sentiment scores from customer reviews
  • Model Development: Built and compared ARIMA, SARIMA, and ARIMAX models, with the ARIMAX model incorporating sentiment scores as exogenous variables
  • Feature Engineering: Created lag features, rolling averages, and seasonal indicators to capture complex patterns

Key Findings

The integration of sentiment analysis significantly improved forecast accuracy. The ARIMAX model with sentiment features achieved ~15% RMSE reduction compared to traditional ARIMA models, demonstrating that customer sentiment is a valuable predictor of future sales trends.

Technical Implementation

Utilized Python's statsmodels library for time series modeling, NLTK for sentiment analysis, and created interactive visualizations using Matplotlib and Seaborn to communicate findings to stakeholders.

Business Impact

This approach enables retailers to better anticipate demand fluctuations, optimize inventory management, and align marketing strategies with predicted sentiment-driven sales patterns.

03

ETL Pipeline Optimization & Data Warehouse Design

Redesigned SQL queries and ETL workflows to improve data processing efficiency for BI systems.

Impact: 15% reduction in query execution time and improved data freshness.

Project Overview

Completed during my Database Systems and Big Data module at the University of Liverpool, this project involved redesigning an entire ETL pipeline to support real-time analytics and improve data warehouse performance.

Challenges Addressed

  • Slow Query Performance: Original queries taking 2-3 minutes for basic reports
  • Data Staleness: Batch processes causing 12-24 hour delays in data availability
  • Scalability Issues: System struggling with growing data volumes (10M+ records)
  • Maintenance Complexity: Fragmented ETL scripts difficult to debug and update

Solution Architecture

Implemented a modular ETL framework using Python and SQL with the following components:

  • Incremental loading strategy instead of full refreshes
  • Star schema redesign for optimized analytics queries
  • Indexed views and materialized aggregations for common queries
  • Partitioning strategies for large fact tables
  • Automated data quality checks and alerting

Performance Improvements

Query execution time reduced from avg 150s to 127s (15% improvement). Data freshness improved from 24 hours to near-real-time (5-minute intervals). System now handles 3x data volume without performance degradation.

Best Practices Implemented

Documentation of all ETL processes, version control for SQL scripts, automated testing framework, and monitoring dashboards for pipeline health.

SQL Python ETL Data Warehouse Optimization PostgreSQL
